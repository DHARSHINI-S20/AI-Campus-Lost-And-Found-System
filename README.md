# AI Campus Lost and Found System

A web-based platform that helps students report, search, and recover lost items within a college campus.

## Features

- User Registration & Login
- Post Lost Items
- Post Found Items
- Image Upload Support
- Search & Filter System
- Item Matching
- User Leaderboard
- MySQL Database Integration

## Tech Stack

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Project Structure

lost_found/

├── logout.php

## Installation

1. Clone the repository
2. Import schema.sql into phpMyAdmin
3. Place project inside htdocs
4. Start Apache and MySQL
5. Open localhost/lost_found
